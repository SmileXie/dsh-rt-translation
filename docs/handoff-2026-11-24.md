# 2026-11-24 工作交接：多行历史字幕

> 承接 [`2026-11-23`](handoff-2026-11-23.md)。本次完成多行滚动历史字幕，并补齐上一轮遗留的文档与测试。

## 本次需求

在已完成“控制条入窗 / 会议默认双语 / 译文不被下一句原文顶掉”的基础上，新增：

> 支持显示多行（2~5 行）的原文字和翻译文字，最后一行为当前正在说话的，前面几行为最近几句话的历史。

## 实现方式

### 行模型

- `subtitle.maxLines` 现在表示**句子行数（2~5）**：最后一行为当前正在说的话，上方为最近几句历史。
- 每行显示「小字原文 + 大字译文」；历史行不透明度 0.7，当前行 1.0。
- 新句子从底部进入；超过行数后最旧的一行滚出。
- 译文刚出现时，即便下一句已经开始，也会多保留一行，直到 `minReadMs` 满足才允许滚出。
- `holdMs` 改为“静音清屏”：最新一行超过 `holdMs` 没有更新时，清空全部行。

### 配置变化

- `subtitle.maxLines`：2–5，会议默认 3、影视默认 4。
- `subtitle.minReadMs`：译文最短可读时间，会议 1800 ms、影视 1500 ms。
- `subtitle.holdMs`：静音清空时间，均为 6000 ms。
- 移除 `subtitle.display`（`primary` / `all`）——多行窗口取代了原来的单行/多行切换。
- 控制条「行数」改为「行数（句）」，范围 2–5。

### 代码改动

- `src/config.ts`：预设置调整、移除 `display`、`maxLines` 2–5。
- `src/subtitle/protocol.ts`：`StylePayload` 移除 `display`。
- `src/controller.ts`、`src/index.ts`：`SubtitleModel.maxCues = max(3, maxLines + 1)`，为历史行和当前句留位置。
- `src/ui.ts`：`maxLines` 钳制到 2–5，移除 `display` 补丁。
- `assets/overlay/overlay.ps1`：
  - 用 `Select-VisibleCues` 取代 `Select-DisplayedCue`：滚动窗口 + `minReadMs` 保留一行 + 当前句在最后；
  - `Render-Cues` 按行渲染并给历史行降透明度；
  - `Remove-IdleCues` / `Expire-Cues` 只做静音清屏，不再按单条年龄逐条删除；
  - `-SelfTestRows` 纯状态机自检（9 个断言，不弹窗），`-SelfTestHold` 保留为别名。
- `client.js`：行数步进器改为 2–5，标签「行数（句）」。
- 测试：config / controller / protocol / ui / overlay-restart 更新；`npm test` 74/74。
